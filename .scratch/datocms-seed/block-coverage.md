# Block coverage

Tracks the Core's Blocks against a reference set: DatoCMS Schema Recipes plus the official Next.js Starter Kit. DatoCMS has no native Blocks, so this is the closest official baseline. Native content shapes (Structured Text nodes, marks, field types) are a closed set and are all handled by the Core; see `docs/research/datocms-base-blocks.md`.
